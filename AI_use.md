# AI Use Declaration

Portions of the ActSim documentation, including the user guide, API reference descriptions, and tutorial notebook text, were drafted with Claude Code (Anthropic) Opus 5 or ealier version in May 2026.

The author reviewed, revised, and verified all generated text against the code and its actual behavior, including every example, parameter description, and formula. The author accepts full responsibility for the documentation.

AI was not used to choose the simulation methods or write the core algorithms.

If the documentation and the code disagree, the code is authoritative. Please open an issue.

This declaration follows the draft *CAS Policy on the Responsible Use of Artificial Intelligence in Research and Publications* (Draft 2.0).
